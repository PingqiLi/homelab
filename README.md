# Homelab 装修施工说明（给设计师/施工方）

本说明只保留施工需要的信息，避免技术术语。

## 1. 机柜位置与尺寸

- 机柜建议：18U~22U，深度 >= 600mm（优先 800mm）。
- 机柜位置优先：设备间 / 储物间 / 生活阳台柜。
- 不建议放在卧室、儿童房、床头背墙（会有噪音与热量）。
- 机柜前后建议各预留 >= 60cm 检修空间。
- 若做封闭柜体，需要预留进风/排风。

## 2. 电力要求（强电）

- 机柜区至少 2 组独立插座回路（建议每组 16A）。
- 含义：从配电箱单独拉两路电，不与普通房间插座混用。
- 机柜内使用 PDU，便于分路供电。
- 预留 UPS 位置（后续给路由/交换机/NAS/服务器供电）。

## 3. 网线与弱电要求

- 全屋网线标准：Cat6A（按 10GbE@100m 施工）。
- 所有网口“单独一根线”回机柜配线架。
- 不允许房间之间串联、分叉。
- AP 与摄像头全部有线回机柜，优先 PoE 供电。
- 所有线缆两端做标签（房间-点位-编号）。
- 关键管线建议预留 20%~30% 空余。

## 4. 零火线要求（智能开关相关）

- 计划做智能开关的位置，一律按“零火双线”施工。
- 零线进底盒，底盒深度需能容纳智能模块。
- 窗帘电机/智能面板位提前确认供电与底盒尺寸。

## 5. 点位数量（本次确定）

- 书房主工位：4 个网口。
- 客厅电视区：4 个网口。
- 每个 AP 点位：1 个网口（PoE）。
- 每个摄像头点位：1 个网口（PoE）。
- 机柜侧交换机端口建议预留 20%~30% 空口。

> 说明：实验设备主要放机柜；书房终端可通过 Wi-Fi/AP 使用。

## 6. 远程 3D 打印预留

- 打印机建议放非卧室、可排风位置。
- 点位预留：2 个电源插座 + 1 个网口 + 摄像头视角位。

## 附：术语解释

- 独立回路：从配电箱单独拉一组电，单独空开，不和其他房间混用。
- 星型回机柜：每个网口单独回机柜，不串联。
- PoE：网线同时传数据和供电，可给 AP/摄像头供电。
- Cat6A：本次选用的网线标准，可支持 10G 家庭局域网。
