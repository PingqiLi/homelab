# Homelab 装修施工说明（设计师/施工方）

目标：本说明用于新家弱电与设备位施工，重点保证网络稳定、后续可扩展、噪音可控。

## 1) 机柜与位置要求

- 机柜建议：18U~22U，深度 >= 600mm（优先 800mm）。
- 位置优先：设备间 / 储物间 / 生活阳台柜。
- 不建议：卧室、儿童房、床头背墙（噪音+发热）。
- 检修与散热：机柜前后建议各预留 >= 60cm；封闭柜需有静音排风。

## 2) 强电与供电

- 机柜区至少 2 组独立回路（建议 16A）。
- 机柜内使用 PDU，网络设备与服务器分路。
- 预留 UPS 位置（后续接入软路由/交换机/NAS/Proxmox）。

## 3) 弱电与布线

- 全屋网线标准：Cat6A。
- 布线方式：所有点位星型回机柜配线架。
- AP/摄像头全部有线回程，优先 PoE 供电。
- 线缆两端统一标签（房间-点位-编号）。
- 关键管线建议预留 20%~30% 余量，便于后期增补。

## 4) 零火线要求（智能化相关）

- 计划使用智能开关的位置，一律按“零火双线”施工。
- 零线入底盒，底盒深度适配智能模块。
- 窗帘电机/智能面板位置提前确认供电与底盒尺寸。

## 5) 点位数量（本次确定版）

- 书房主工位：4 个网口（主力有线 + 备用扩展）。
- 客厅电视区：4 个网口（电视/盒子/主机/备用）。
- 每个 AP 点位：1 个网口（PoE）。
- 每个摄像头点位：1 个网口（PoE）。
- 机柜侧交换机端口容量需预留 20%~30% 空口。

> 说明：实验设备主要放机柜，书房终端可通过 AP 接入，因此当前按 4 口实施。

## 6) 网络结构（施工理解）

- 主干：光猫 -> OPNsense 软路由 -> 核心交换机。
- 服务器区：NAS / Proxmox / 主力工作站（建议 10G 上联）。
- 接入区：PoE 交换机 -> AP / 摄像头 / IoT 网关。

VLAN 逻辑：
- VLAN10 Main
- VLAN20 IoT
- VLAN30 Guest
- VLAN40 Server
- VLAN50 Camera
- VLAN60 Lab
- VLAN99 Mgmt

## 7) 远程 3D 打印预留

- 打印机建议放非卧室、可排风位置。
- 点位预留：2 个电源插座 + 1 个网口 + 摄像头视角位。
- 远程访问建议走 WireGuard，不做公网裸露。
